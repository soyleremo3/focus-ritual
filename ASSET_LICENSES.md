# Asset Licenses

FocusRitual bundles no third-party stock photography or audio. Every asset shipped in
`assets/` is either originally generated for this project or an unmodified default from
the Expo project template.

## Ambient sound loops (`assets/sounds/`)

`rain.wav`, `ocean-waves.wav`, `wind.wav`, `white-noise.wav`, `brown-noise.wav`,
`pink-noise.wav`, and `fireplace.wav` are procedurally synthesized PCM audio, generated by
[`scripts/generate-sound-assets.mjs`](scripts/generate-sound-assets.mjs) — no external
recordings, samples, or libraries involved. Re-run the script to regenerate or tweak them:

```bash
node scripts/generate-sound-assets.mjs
```

Original work, created for FocusRitual. No external license applies; no attribution
required. Expanded from 3 to 7 loops in Phase 5 (Sound Library & Mixer Polish) — every
addition follows the same synthesis-only policy as the original three, so the bundled
library stays redistribution-safe by construction rather than by sourcing diligence.

## Focus Space scenes

Bundled Focus Space backdrops (Amber Study, Rain Window, Midnight Forest — see
`src/theme/scenePalettes.ts`) are drawn in code as gradients and vector shapes
(`SceneBackdrop.tsx`), not photographic assets. Nothing to license.

## App icons and splash image (`assets/images/`, `assets/expo.icon/`)

`icon.png`, `splash-icon.png`, `favicon.png`, `android-icon-*.png` are unmodified
placeholder defaults from the Expo `create-expo-app` project template, used as scaffolding
until the app has its own icon design. Provided under the same terms as the Expo template
itself (MIT — see `LICENSE`).

## Custom Focus Space photos (out of scope for this file)

Phase 4 lets a user add their own photos as custom Focus Spaces (`src/lib/imagePicker.ts`
copies the picked photo into local, per-device app storage). These photos are user content,
never bundled with the app or committed to this repository, so they carry no license entry
here — this file only tracks assets FocusRitual itself ships in `assets/`.
